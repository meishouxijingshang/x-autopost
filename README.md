# X 自動投稿（1日5回・分はランダム）

8時・10時・12時・18時・21時（日本時間）の各時間帯に、分をランダムにして投稿します。

## 毎日やること

前日までに `posts/` フォルダに **日付名のファイル** を作るだけです（例: `posts/2026-11-16.txt`）。
GitHubのスマホアプリやWebからも作成できます。

```
1つ目の投稿（8時台）
---
2つ目の投稿（10時台）
---
3つ目（12時台）
---
4つ目（18時台）
---
5つ目（21時台）
```

ファイルを保存すると、Issues に「投稿確認 2026-11-16」が自動で作られ、プレビュー（文字数つき）が届きます。
**内容に問題がなければ、そのIssueに `OK` とコメントしてください。OKがない投稿は投稿されません。**

- OKの後にファイルを直すと、新しいプレビューが届きます。もう一度 `OK` が必要です。
- 投稿の直前に承認を確認するので、その時間帯の投稿時刻までにOKすれば間に合います。
- 投稿されるとIssueにリンクが付き、その日の最後の投稿が終わるとIssueは閉じられます。
- OKが有効なのはリポジトリのオーナー（あなた）のコメントだけです。
- 通知を受け取るには、GitHubスマホアプリの通知をONにしておいてください。
- `---` だけの行で投稿を区切ります。
- 投稿が4つしかなければ、5つ目の枠はスキップされます。
- 1投稿は全角140字（半角280字）までです。
- URLを入れると1投稿あたりの料金が上がるので注意してください。

## 初回セットアップ

1. **X Developer Portal**（developer.x.com）でアプリを作成し、クレジットを少額チャージします。
2. アプリの **User authentication settings** で権限を **Read and write** にします。
   ※ 権限を変えたら、Access Token を **再発行** してください（古いトークンでは投稿できません）。
3. 次の4つをメモします: API Key / API Key Secret / Access Token / Access Token Secret
4. GitHubで新しいリポジトリを作り、このフォルダの中身をアップロードします。
5. リポジトリの **Settings → Secrets and variables → Actions** で、次の名前で4つ登録します。
   - `X_API_KEY`
   - `X_API_SECRET`
   - `X_ACCESS_TOKEN`
   - `X_ACCESS_TOKEN_SECRET`
6. **Actions** タブ → 「X auto post」→ **Run workflow**（テストモードON）で動作確認します。
   承認済みなら、ログに投稿予定の文が出ます。
7. `posts/` に日付ファイルを置くと、「Post review」が動いて確認用Issueが作られることを確認します。

## 注意

- **リポジトリは公開（Public）を推奨**します。投稿のたびに最大1時間ほど待機するため、
  非公開（Private）だとGitHubの無料枠（月2,000分）を超える見込みです（月約5,000分）。
  APIキーはSecretsに入れるので公開しても漏れませんが、翌日の投稿文は事前に見える状態になります。
- GitHubの起動は混雑時に遅れることがあります。遅れて枠の予定時刻を過ぎた場合は、すぐに投稿します。
- 費用目安: テキストのみ1日5投稿で月2〜3ドル程度（X API従量課金）。
